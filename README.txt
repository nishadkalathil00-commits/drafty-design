DRAFTY DESIGN — Independent Creative Studio Website

FILES
- index.html : website structure and content
- style.css  : all visual styling and responsive layouts
- script.js  : navigation, project filters, scroll progress, reveal effects

HOW TO PREVIEW
1. Keep all three files in the same folder.
2. Double-click index.html to open it in your browser.
3. Internet is needed for Google Fonts. All layout and interactions work without a build step.

BEFORE PUBLISHING
- Replace the five illustrative project mockups in index.html/CSS with your real portfolio images.
- Update the email address hello@draftydesign.in in index.html to your actual email.
- Add your Instagram / Behance / YouTube links when ready.
- The project cards currently link to the contact section as placeholders.

This is a static HTML/CSS/JavaScript website. No framework or build command is required.
